# Официальный комплект задач

Файлы организаторов не перепубликуются во внешнем GitHub-репозитории. Для локальной проверки baseline официальный архив должен быть скачан с:

```text
https://hack-contest.hse-hack-club.ru/tasks/archive.zip
```

После распаковки ожидается структура `official/problems/<номер задачи>/...`. Локальная рабочая копия уже содержит этот комплект.
