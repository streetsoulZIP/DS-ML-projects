# Минимальный baseline

`countertests/` содержит пять малых допустимых входов, найденных прямым анализом исходников. Каждый тест локально воспроизводит расхождение между официальным эталоном и соответствующим неправильным решением.

Проверка:

```powershell
python baseline/verify.py
```

Имена файлов уже соответствуют формату платформы и упакованы непосредственно в корень `submission.zip`.

Полный запуск без браузера из корня репозитория:

```powershell
python contest.py submit
```

Команда повторно проверяет контртесты и ZIP, отправляет архив через официальный API, возобновляет опрос той же посылки после прерывания, сохраняет итоговый JSON в `baseline/results/` и создаёт Git-коммит. Флаг `--push` дополнительно отправляет его в настроенный локальный `origin`.

В текущей среде GitHub-цель для Codex зафиксирована в `github-target.json`. Локальный `origin` не требуется: Codex публикует изменённые артефакты через подключённый GitHub-коннектор после завершения сценария.

Если все контртесты архива уже имеют статус `HACKED`, повторной отправки не будет: сценарий только зафиксирует текущий прогресс. Отдельно обновить снимок прогресса можно командой `python contest.py snapshot`.
Неизменившийся ответ API не создаёт новый коммит.

Ключ читается из переменной `HACK_TOKEN` либо из игнорируемого Git файла `.secrets/participant.token`. Для разовой ручной настройки предусмотрена команда `python contest.py configure` со скрытым вводом.
